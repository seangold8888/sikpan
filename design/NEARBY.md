# 일반식당 확장 기획 — 걸어갈 수 있는 식당까지 한 랭킹에

2026-09-11. 사용자 결정 반영.

## 왜

구내식당은 메뉴가 매일 바뀌어 "오늘 메뉴로 매긴 점수"가 성립한다. 일반식당은 메뉴가 고정이라
같은 방식이면 순위가 매일 같다 → 목록이지 추천이 아니다. 그래서 추천의 뜻을 바꾼다.

- 구내식당: 오늘 **메뉴가** 좋은 곳
- 일반식당: 오늘 **나에게** 맞는 곳 — 거리·가격·최근 며칠 먹은 것과의 균형

둘을 **한 랭킹**에 세운다. 구내식당 7,500원과 일반식당 9,000원이 같은 가성비 축에서 비교되는 것이
통합의 값어치다.

## 결정 (2026-09-11)

| 항목 | 결정 |
|---|---|
| 구조 | 통합 랭킹 + "구내식당 / 일반식당" 필터. 탭 분리 안 함 |
| 반경 | 기본 도보 10분 ≈ 700m. 선택지 5분(350m) / 15분(1,000m). 기준은 검색한 건물 |
| 메뉴·가격 | **메뉴판 사진 → 기존 OCR**. 카카오 상세 비공식 데이터는 긁지 않는다(링크만) |
| 제외 업종 | 술집·호프, 배달 전문. 카페·패스트푸드는 포함 |

## 유지 원칙

- 숫자로 고른다. 근거와 계산을 보여 준다.
- 모르는 값은 0이 아니라 중립 0.5.
- 메뉴판에 인쇄된 값만. 추정 금지.
- 새 섹션을 만들지 않는다. 카드와 필터 안에서 푼다.

## 데이터

| 항목 | 출처 | 상태 |
|---|---|---|
| 식당 목록·좌표·업종·링크 | 카카오 로컬 API (`scripts/nearby.py`, 키 필요) | 됨. 질의당 45건 상한 → 원을 4분할해 가며 수집 |
| 가늠용 | OSM Overpass | 반경 700m 26곳뿐(누락 많음). 하한선으로만 |
| 메뉴·가격 | 메뉴판 사진 → `scripts/ocr.py` | 파이프라인 있음. 점심 다니며 입구 메뉴판 한 장씩 |
| 폐업 여부 | 서울시 일반음식점 인허가 공공데이터 | 보조. 카카오 목록 검증용 |
| 영업시간·휴무 | 사진 또는 카카오 링크 | 부분 |
| 대기줄·혼잡 | 없음 | 포기 |

**확인할 것 — 카카오 로컬 검색 결과 저장.** 카카오 API 이용약관에 검색 결과의 장기 저장·재배포 제한
조항이 있는지 확인이 필요하다. 문제가 되면 저장소에는 id·이름·좌표·업종만 최소로 두거나,
인허가 공공데이터(저장 자유)를 목록의 뼈대로 쓰고 카카오는 링크 조회에만 쓴다.

**배달 전문은 업종으로 못 가린다.** 카카오 업종은 "음식점 > 치킨"까지라 홀 유무를 모른다.
`data/places.json` 처럼 손으로 `delivery_only: true` 를 표시한다.

## 점수 — 일반식당 축

| 축 | 구내식당 | 일반식당 |
|---|---|---|
| 가까움 | 기준 건물 거리 | 같음 |
| 가성비 | 가격, `_price_score` | 대표 점심가, 같은 함수(반경 안 중앙값 기준) |
| 반찬수·메인수·희소성 | 메뉴판 | 없음 → 중립 0.5 |
| **돌려먹기 (신설)** | 적용 | 최근 7일 먹은 업종(한·중·일·양·분식·카페…)과 겹치면 감점 |
| 회피 | 최근 먹은 곳 `ate` | 같음 |

매일 순위가 달라지는 힘 = 돌려먹기 + 회피. 이 둘이 없으면 일반식당 추천은 죽는다.

## 화면

- 검색줄에 반경 선택(도보 5 / 10 / 15분).
- 카드에 배지 "구내식당 / 일반식당" + 업종. 필터로 끄고 켠다.
- 일반식당 카드: 대표 메뉴·가격이 있으면 점수, 없으면 "가격 미확인" + 거리·업종·카카오 링크.
- 사진 등록: GitHub 이슈에 사진을 올리면 Action 이 OCR 해 반영(휴대폰에서 바로). 2차.
- 지도: 일반식당은 작은 점. 점수 있는 곳만 이름표.

## 단계

1. **목록** — 카카오 REST 키 → 반경 1km 음식점·카페 → `data/nearby.json` + 업종별 개수 리포트. 사이트엔 아직 안 올린다.
2. **화면** — 반경 필터, 일반식당 카드(거리·업종·링크만), 지도 점.
3. **가격** — 사진 OCR 입력 경로. 가격 있는 곳부터 점수.
4. **돌려먹기 축 + 통합 랭킹.**

## 키

`KAKAO_REST_KEY` — developers.kakao.com → 내 애플리케이션 → 앱 키 → REST API 키.
로컬은 사용자 환경변수, 자동화는 GitHub secret. 값은 저장소·대화에 적지 않는다.
