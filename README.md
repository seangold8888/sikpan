# SIKPAN 식판

주판(ZOOPAN) 자매품. 반찬까지 세어서 점심을 고른다. (옛 이름: 가산 런치보드 / Gasan Lunch Board)

서울 가산디지털단지 구내식당의 오늘 메뉴를 한국어와 영어로 한 페이지에 모아 보여준다.
대부분 7,500원이고 그 건물에 근무하지 않아도 누구나 들어가 먹을 수 있는 개방형 식당이라,
근처 직장인뿐 아니라 이 동네를 찾는 외국인에게도 쓸모가 있다.

## 어떻게 돌아가나

가산의 구내식당들은 매일 아침 카카오톡 채널에 메뉴판을 **사진으로** 올린다. 텍스트로
받아올 수 있는 곳이 없어서, 사진을 읽어 글자로 바꾸는 단계가 필요하다.

    scripts/fetch.py   식당 목록·주소·길찾기 링크·메뉴판 사진 주소를 모은다
    scripts/ocr.py     사진을 읽어 한국어 원문과 영어 번역으로 바꾼다
    scripts/build.py   docs/index.html 을 만든다

`.github/workflows/daily.yml` 이 월~토 오전 한 번 (한국시간 10:00) 이
세 단계를 돌리고, 바뀐 것이 있을 때만 커밋한다. 식당마다 올리는 시각이 달라 한 번만
확인해서는 늦게 올리는 곳을 놓친다.

직접 돌려보려면:

```bash
python scripts/fetch.py && python scripts/ocr.py && python scripts/build.py
```

## 판독에 대해

`ocr.py` 는 Claude 의 이미지 인식을 쓴다. `ANTHROPIC_API_KEY` 가 없으면 판독 단계를
건너뛰고, 사이트는 메뉴판 사진과 식당 정보만으로 그대로 동작한다. 영어 메뉴만 빠진다.

판독 결과는 사진의 sha256 을 키로 `cache/ocr/` 에 저장한다. 같은 사진은 다시 읽지 않으므로
하루에 세 번 돌려도 새로 올라온 메뉴판만 비용이 든다. 60일이 지난 결과는 자동으로 지운다.

## 메뉴판 날짜 확인

어제 메뉴가 그대로 걸려 있거나 내일 것이 먼저 올라오는 일이 실제로 있다. `build.py` 는
메뉴판에 인쇄된 날짜를 오늘과 대조해서, 다르면 그 식당 카드에 며칠자 메뉴판인지 표시하고
목록 맨 뒤로 보낸다. 주간 식단표처럼 날짜가 범위로 적힌 경우는 그 범위에 오늘이 들어가는지
본다.

## 손으로 관리하는 것

`data/places.json` 에는 사진에서 읽을 수 없는 것만 적는다. 영문 식당명, 식권 가격,
현지 추천 순위, 그리고 카카오톡 채널이 없어 자동 수집이 안 되는 곳(`extras`)이다.
키는 `data/sources.json` 의 `id` 이고, 이 id 는 식당 이름에서 만들어지므로 이름이 바뀌지
않는 한 그대로 유지된다.

## 출처

메뉴판 사진과 식당 정보는 각 식당이 카카오톡 채널에 공개한 것이고,
그것을 하루 단위로 모아 두는 <https://koreaward-6.github.io/> 를 통해 가져온다.
사진은 내려받아 다시 올리지 않고 카카오 CDN 주소를 그대로 참조한다.
